# APOIO — AVALIAÇÃO PRÁTICA SESI — HTML, CSS e JavaScript

Este projeto contém a estrutura inicial da avaliação e uma pasta `APOIO` destinada aos exemplos estudados durante as aulas.

## Regras da avaliação

- É permitido utilizar a Internet para pesquisa.
- **Não é permitido utilizar Inteligência Artificial generativa para produzir, corrigir ou explicar o código da avaliação.**
- É permitido consultar documentação, tutoriais e exemplos técnicos.
- Sempre que você pesquisar algo na Internet e utilizar a informação para desenvolver sua solução, **registre a referência utilizada**.
- Dê preferência a fontes educacionais e documentação técnica, especialmente o **W3Schools**.
- Não copie uma solução completa de outro projeto. Entenda, adapte e teste o que encontrar.
- O professor poderá solicitar que você explique qualquer parte do código desenvolvido.

## 🧭 Como pesquisar

Prefira pesquisar pelo conceito, não pela solução completa.

Exemplos:

- `W3Schools addEventListener`
- `W3Schools querySelector`
- `W3Schools classList toggle`
- `W3Schools CSS transition`
- `W3Schools CSS hover`
- `W3Schools media query 768px`
- `W3Schools input type color`

Evite pesquisar frases como:

- `código pronto tarefa 01`
- `resposta avaliação SESI`
- `código completo painel de controle`

## Dica

Se encontrar um exemplo parecido com o que precisa, não copie imediatamente.

Primeiro tente responder:

1. O que esse código faz?
2. Qual parte eu realmente preciso?
3. O que preciso modificar?
4. Como posso testar se entendi?

O objetivo da avaliação é demonstrar **capacidade de desenvolver e resolver problemas**, e não apenas encontrar código pronto.
